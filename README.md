# RAHMA - Online Donation Platform

**SKJM Chapparappadavu Range Shema Samithi**

A production-ready Progressive Web Application (PWA) for mosques, madrasas, and charitable organizations to collect online donations with automated receipts.

## 🌟 Features
- Online Donation with UPI, Google Pay, PhonePe, Net Banking, Cards
- Automatic PDF Receipt Generation with QR Code
- Multi-Language: English, Malayalam, Arabic (RTL)
- PWA: Add to Home Screen on Android & iPhone
- Admin Dashboard with Excel & PDF Reports
- Campaign Management

## 🚀 Tech Stack
- **Frontend**: React (Vite), Bootstrap 5, PWA
- **Backend**: Django, Django REST Framework, JWT
- **Database**: SQLite (dev) / PostgreSQL (production)
